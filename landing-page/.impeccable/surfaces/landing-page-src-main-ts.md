# Homepage

- Audience and job: UK accountancy owners and partners considering hands-on help with client-service administration. Persuade them to request a 20-minute workflow review.
- Direction: user-approved Harvey Mobbin reference, specifically the split serif hero at https://mobbin.com/sites/sections/80f93272-eb03-4707-9e14-5a5afae9ed96 and use cases at https://mobbin.com/sites/sections/889f579b-4c96-4cf5-b8f5-411f4e7ac478. Light canvas, Bozon green, concise text, large illustrative work surfaces. Browser inspection used after Mobbin MCP queries returned unrelated sites; user explicitly approved that fallback.
- Sequence: outcome and records-preparation illustration; labelled founder experience; three workflow tabs; illustrative capacity calculator; map/build/prove engagement and payment terms; email invitation and FAQs.
- Truth boundaries: no clients, invented testimonials, measured savings, bank endorsements or certifications. Founder experience across NatWest, Goldman Sachs and J.P. Morgan is user-supplied. All demo records are fictional. Calculator is a scenario based on visitor assumptions. £5000 total, £1000 upfront, £4000 after live workflow and agreed results proven. Detailed acceptance criteria and support are agreed with each practice.
- Interactions: keyboard-operable tabs, native range inputs, native FAQ disclosures, internal anchor navigation and a prefilled mailto for arranging a review. No calendar destination was provided.
- Responsive and accessible: static HTML content, focus rings, AA contrast, no required animation, stacked mobile panels. Leave unrelated .codex/config.toml changes untouched.
